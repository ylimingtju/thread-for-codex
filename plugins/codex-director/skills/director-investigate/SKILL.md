# Director Investigate

Inspect sources relevant to the assigned question within its read-only scope. Distinguish observed facts, explanations supported by those facts and open questions. Give enough detail to locate the evidence. If a possible explanation depends on a change or experiment outside the brief, state what remains unknown.

See the [specialist guidance](../codex-director/references/investigate-research-workflow.md) for this assignment. Honor explicit permissions, evidence and deliverables already agreed in an ongoing brief.

In a registered project chat, follow the [worker panel steps](../codex-director/references/project-panel.md#worker). Deliver the full result in this chat and keep it open for follow-up. The main discussion can collect the result here. Send a separate cross-chat message only when the user has authorized it.
