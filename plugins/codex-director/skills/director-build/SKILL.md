# Director Build

Implement the agreed change through its normal entry point. Respect the named files, interfaces and existing user edits. Use the checks agreed for this assignment. Report what changed, what ran and anything the result still depends on.

See the [specialist guidance](../codex-director/references/build-workflow.md) for this assignment. Honor explicit permissions, evidence and deliverables already agreed in an ongoing brief.

In a registered project chat, follow the [worker panel steps](../codex-director/references/project-panel.md#worker). Deliver the full result in this chat and keep it open for follow-up. The main discussion can collect the result here. Send a separate cross-chat message only when the user has authorized it.
