# Director Deep Plan

Use the current project constraints to recommend a feasible sequence. Explain the material trade-offs, dependencies, decisions that need the user and how to tell when the intended outcome has been reached. Stay in planning mode. Deliver the plan in this chat unless a separate plan document is part of the request.

See the [specialist guidance](../codex-director/references/deep-plan-workflow.md) for this assignment. Honor explicit permissions, evidence and deliverables already agreed in an ongoing brief.

In a registered project chat, follow the [worker panel steps](../codex-director/references/project-panel.md#worker). Deliver the full result in this chat and keep it open for follow-up. The main discussion can collect the result here. Send a separate cross-chat message only when the user has authorized it.
