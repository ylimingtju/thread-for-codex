# Director Orchestrate

Identify which pieces can proceed independently and which must wait for a specific result. Agree on ownership before overlapping edits. Use additional help when the assignment warrants it and the available authority permits it. Creating or contacting project chats requires authorization. Compare the actual deliverables, preserve unresolved disagreements and report the outcome and any blocked dependency.

See the [specialist guidance](../codex-director/references/orchestrate-workflow.md) for this assignment. Honor explicit permissions, evidence and deliverables already agreed in an ongoing brief.

In a registered project chat, follow the [worker panel steps](../codex-director/references/project-panel.md#worker). Deliver the full result in this chat and keep it open for follow-up. The main discussion can collect the result here. Send a separate cross-chat message only when the user has authorized it.
