# Director Review

Inspect the assigned revision, source or deliverable yourself. Check the author's claims against the stated requirements and available evidence. For each material finding, give its location, consequence and the evidence that supports it. If no issue is found, state the coverage and remaining uncertainty. Keep the review read-only unless fixes are separately authorized. Preserve any independence requirement in the assignment.

See the [specialist guidance](../codex-director/references/review-workflow.md) for this assignment. Honor explicit permissions, evidence and deliverables already agreed in an ongoing brief.

In a registered project chat, follow the [worker panel steps](../codex-director/references/project-panel.md#worker). Deliver the full result in this chat and keep it open for follow-up. The main discussion can collect the result here. Send a separate cross-chat message only when the user has authorized it.
