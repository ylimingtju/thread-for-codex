# Director Refactor

Identify the public behavior, callers, stored data and error cases affected by the proposed change. Keep edits within scope and preserve those contracts. Use the checks appropriate to the assignment and report their results. Surface an incompatible change for decision before including it.

See the [specialist guidance](../codex-director/references/refactor-workflow.md) for this assignment. Honor explicit permissions, evidence and deliverables already agreed in an ongoing brief.

In a registered project chat, follow the [worker panel steps](../codex-director/references/project-panel.md#worker). Deliver the full result in this chat and keep it open for follow-up. The main discussion can collect the result here. Send a separate cross-chat message only when the user has authorized it.
