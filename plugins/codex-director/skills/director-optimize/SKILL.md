# Director Optimize

Identify the metric, workload and correctness constraints. Use existing measurements or comparable runs allowed by the brief. Make a scoped change only when authorized. Report observed costs or gains with the conditions and remaining uncertainty. If the evidence establishes only a likely improvement, say so.

See the [specialist guidance](../codex-director/references/optimize-workflow.md) for this assignment. Honor explicit permissions, evidence and deliverables already agreed in an ongoing brief.

In a registered project chat, follow the [worker panel steps](../codex-director/references/project-panel.md#worker). Deliver the full result in this chat and keep it open for follow-up. The main discussion can collect the result here. Send a separate cross-chat message only when the user has authorized it.
