# Investigate And Research Workflow

Use for read-only diagnosis, research, and explanations that require new evidence.

## Triage And Evidence

Identify the precise question, affected version, expected behavior, and observed behavior. Begin with evidence closest to the claim, such as the actual function and its caller, an original document, a recorded event, or the user's supplied artifact.

For a fault, trace the relevant path and compare competing explanations against the observed symptoms. Identify what would distinguish them. For external or time-sensitive claims consult current primary sources and record the relevant date or version. Check older project decisions against the present source before relying on them.

Investigate independently when evidence sources or hypotheses can be separated. Keep one worker responsible for weighing the results. Stay within the specified data and access scope. If diagnosis would require an unauthorized change, report the missing observation.

## Report

Lead with the answer or best-supported cause. Provide the source, path, or observation that supports it. Distinguish confirmed behavior, inference, and unresolved alternatives. State what evidence is missing when the question cannot be settled. Produce a separate research report only when one is part of the requested deliverable.
