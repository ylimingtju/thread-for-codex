# Optional Prompt Artifact Notes

Use a prompt file when the user requests the exact payload, a chosen tool needs a file, or a previously agreed handoff requires it. Ordinary assignments and small approved Browser submissions can carry the prompt directly.

## Artifact Contents

Keep the exact question, permitted source excerpts or file references, version, needed constraints, and the expected answer. For uploads use only the data the user authorized for that service. Exclude credentials, tokens, private links, unrelated transcript text, and sensitive raw data.

Use the agreed location for a deliverable or an existing workflow file when resuming it. For temporary uploads use a private temporary location and clean up only files created for that operation after they are no longer needed. Preserve previously promised outputs. Delivery of a prompt file and receipt of an external answer are distinct outcomes. For the latter follow the [Browser review workflow](browser-chatgpt-oracle-workflow.md).
