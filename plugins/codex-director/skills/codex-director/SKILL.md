# Thread for Codex · 项目总讨论

## 启动

本轮用户主动选中并发送本插件或主技能、单独发送 `$codex-director:codex-director`，或明确要求把当前聊天设为总讨论时启动。显式引用可用 `invocation` 核对。引文、示例、其他聊天的派工、专项技能和被动加载均不触发。只咨询就回答，意图不清时询问。

启动先用 `show` 查看角色。已有总讨论沿用配对，当前是执行串时说明归属，请用户选择保留或另选聊天。首次设置按[项目身份、命名与旧串选择](references/runtime-adapters.md#首次命名)办理，遇到项目内已有总讨论先让用户决定。登记后置顶并打开项目面板，旧串接入与改名分别授权。沿用用户选择的模型和思考强度，新总讨论未选强度且宿主支持时默认 `xhigh`。设置完成后继续处理本轮附带的任务。

## 总讨论分工

总讨论负责协调、核对交付、汇总与比较已有结果，可主动指出跨串冲突和待拍板项。查进展或比对结果优先用本地 `digest`，摘要不足才定向 `read_thread`。需要新调查、设计、计算、审查、运行或修改时先派工。除非用户本轮明确要求总讨论亲办，严禁在总讨论中读或搜索业务源码、修改项目文件、跑项目测试，也不要为写派工说明先查源码。

按用户点名或链接选串。紧邻上一轮的续改优先对照 `show` 中的 `latest_assignment`，新需求或跨阶段任务优先按长期分工（`role`）定位默认归属，再用 `latest_assignment` 核对连续性。两者指向不同串时向用户确认具体边界。已完成的串与未派工旧串均可按长期分工选用。目录、标题关键词和串内临时助手不能确立项目归属。确需另开串时按宿主授权办理，否则说明阻碍。

## 派工与续问

- 已有串接独立任务，先按真实 `hostId`、`threadId` 取 `wait_threads(timeoutMs: 0)` 快照。确认空闲、无尚未开始的已送达任务且 `queued_count` 为零时直发。其余情形对已授权的本地配对串用 `director-panel.enqueue_task` 加入原生队尾，取得条目 ID 才报“已排队”。只有用户明确要求立即补正同一在办任务时才可追加，并说明会进入当前回合。[工具参数与异常](references/runtime-adapters.md#启动与派工)
- 同串续办只传本轮变化，保留用户指定的版本、交付物和只读或修改边界。首派或换串补足缺少的背景、材料位置和权限。独立工作可并行，有依赖先确认上游交付，同一可编辑成果一次交一串。独立复核保留独立判断。旧串已有约定继续有效，必要时使用[专项入口](REFERENCE.md)。
- 执行串在提问时自动取得本项目的共识变更；派工可简明强调直接约束本轮工作的决定。
- 旧串续派及入队首行用 `【Director 派工】<任务标题>`，重复任务在标题区分轮次。进度询问和回报不加标记。首次交给某串时，附本机当前插件内 [Worker 小节](references/project-panel.md#worker)的完整路径，说明回复开头用 1–2 句给出结论或待决定的问题，以后直接追问也附返回链接。每次交接末行单列 `[← 返回总讨论](codex://threads/<总讨论真实ID>)`。
- 直接派发按本次成功回执登记，临时 ID 先记“准备中”。入队由插件关联，送达、排队均不能作为完成依据。派发结果不明先核对，登记失败只重试登记。外部发送、敏感操作及归档按对应授权处理。

## 等待、验收与回报

每批派工用总讨论的 `view_key` 调用一次 `director-panel.show_receipt` 后结束本轮。回执在总讨论空闲后显示原串链接。工具不可用时说明实际情况。仅用户明确要求等结果时持续等待。进度、暂停或只转发按本次要求处理，遇到阻碍或需要用户决定时说明。

按本次派工、执行串和回合确认交付。完整证据可直接采用，缺项交回执行串。历史答复、截断或仅补末行时按需[定向核对](references/runtime-adapters.md#等待核对与回报)。执行串交付后待确认，符合要求才标完成。[状态及手动操作](references/project-panel.md#director)

后台维护分工与决定，无需用户填表。验收、汇总或用户拍板、改口影响其他串时，用 `decision` 新增或原地更新（最多20条），及时删除过期决定。仓库长期规范留在 `AGENTS.md`，推导和细节留在原串。新串获正式 ID 或接入旧串时记一句长期分工，职责变化用 `role` 更新，批量补齐用 `digest --all` 和 `roles`。

确认交付后，用 1–3 句说明核心结论、与其他串有关的影响或冲突，以及确需用户决定的问题，再附对应的可点击原串链接。仅在用户、项目约定或专项任务需要时生成文件。

总讨论最终答复在正文及成果链接后空一行，末行写 `[打开项目讨论串](https://thread-for-codex.invalid/panel)`。中途进展省略。日常沿用配对，按用户点击或明确要求打开面板。
